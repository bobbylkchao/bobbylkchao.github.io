Open source

AI Phone Agent

I maintain AI Phone Agent, a ready-to-run Node.js and TypeScript starter kit for AI agents that answer real phone calls and talk to customers in real time, built on Amazon Connect, OpenAI SIP, and the OpenAI Realtime API. It handles the incoming-call webhook, call lifecycle, Realtime sideband connection, function tools, human handoff, and a hangup that waits for the agent to finish speaking — so developers can focus on their own prompts and business logic.

Dial +1 844 593 8442 to try the live demo, or read the source at github.com/bobbylkchao/ai-phone-agent.
